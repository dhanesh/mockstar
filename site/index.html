Mock any HTTP API from a folder of JSON.

Mockstar is a Bun-based mock server: static and dynamic responses from JSON config, named JS handlers, pass-through routing, multi-tenancy, scenarios, outbound webhooks and Faker-powered templating — as a CLI, a library embed, or a container.

Install View on GitHub Latest release

Install

Pick the channel that fits your workflow. All of them run the same server.

brew install dhanesh/tap/mockstar
mockstar serve ./mocks

# or keep it running in the background (serves $(brew --prefix)/var/mockstar/mocks)
brew services start mockstar

macOS and Linux, Apple Silicon and Intel. Standalone binary — no Bun install needed.

bunx @dhaneshpurohit/mockstar ./mocks

# or as a dev dependency for library embed
bun add -d @dhaneshpurohit/mockstar

Requires Bun 1.3.0+.

docker run --rm -p 3000:3000 \
  -v "$PWD/mocks:/config/mocks:ro" \
  ghcr.io/dhanesh/mockstar:latest

Multi-arch (amd64 + arm64), non-root, cosign-signed. The image ships no mocks — mount yours.

helm install mockstar oci://ghcr.io/dhanesh/charts/mockstar \
  --namespace mockstar --create-namespace

Single replica by design — journal, scenarios and webhook queue are in-memory.

curl -fsSLo mockstar \
  https://github.com/dhanesh/mockstar/releases/latest/download/mockstar-bun-linux-x64
chmod +x mockstar && ./mockstar --version

Targets: darwin-arm64, darwin-x64, linux-arm64, linux-x64. Each has a .sha256 beside it.

Quick start

Scaffold a mocks folder, serve it, and edit with hot reload.

mockstar init .            # writes mocks/default/example.json + mockstar.config.json
mockstar serve ./mocks     # http://127.0.0.1:3000

curl localhost:3000/hello      # {"message":"Hello from mockstar"}
curl localhost:3000/users/42   # {"id":"42","name":"…","email":"…"}
{
  "$schema": "https://schemas.mockstar.dev/v0.4/mock.json",
  "mocks": [{
    "id": "get-user-by-id",
    "match": { "method": "GET", "path": "/users/:id" },
    "response": {
      "kind": "static",
      "status": 200,
      "body": { "id": "{{request.params.id}}", "email": "{{faker.email}}" }
    }
  }]
}

What it does

Built on Hono on Bun. Targets p99 < 5 ms for static responses.

Static + dynamic mocks

JSON config per resource, with named JS/TS handlers when a response needs logic.

Templating

{{ }} request reflection, Faker data, provider-shape IDs and timestamps — deterministic mode for byte-identical CI.

Multi-tenancy

One directory per tenant, routed by Host or X-Mockstar-Tenant.

Scenarios

Switch a tenant into an error or edge-case state through the admin API.

Outbound webhooks

Retries, circuit breaking and provider-accurate signatures for GitHub, Slack, Stripe, Shopify and Razorpay.

Pass-through + proxy

Forward unmatched routes upstream, or intercept real HTTPS hosts locally with mockstar proxy.

OpenAPI import

Turn an OpenAPI 3.x spec into mock configs, then enhance them with realistic placeholders.

Library embed

launch() in-process for Jest, Vitest and bun test — no port, clean stop().
